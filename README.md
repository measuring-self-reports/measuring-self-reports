# Measuring AI Introspection

A study site that reads introspection experiments on language models as measurements:
a measurement card drawn from metrology, the philosophy of measurement, psychometrics and
consciousness science, applied to 23 experiments.

Site: https://measuring-introspection.github.io/measuring-introspection/

Build: `npm ci && npm run build`. See `docs/SITE_GUIDE.md` for how pages are organized.
