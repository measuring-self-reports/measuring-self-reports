# Measuring AI Self-Reports

A study site that reads experiments on what language models say about themselves as
measurements. It covers three families: introspection, chain-of-thought faithfulness, and
activation verbalizers and natural language autoencoders. A measurement card drawn from
metrology, the philosophy of measurement, psychometrics and consciousness science is applied
to the introspection experiments.

Site: https://measuring-self-reports.github.io/measuring-self-reports/

Build: `npm ci && npm run build`. See `docs/SITE_GUIDE.md` for how pages are organized.
